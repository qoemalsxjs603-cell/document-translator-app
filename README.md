# 문서 번역기 Pro

PPTX, DOCX, XLSX 파일을 업로드하면 중국어 또는 영어로 번역한 파일을 생성하는 Streamlit 웹앱입니다.

## 지원 기능

- PPTX / DOCX / XLSX 업로드
- 중국어 / 영어 번역
- 원본과 같은 파일 형식으로 다운로드
- 여러 파일 동시 업로드
- 번역 로그 엑셀 다운로드
- 세션 내 번역 캐시
- 선택형 용어집 업로드
- PPT 표 및 일부 그룹 오브젝트 처리
- Word 본문 / 표 / 헤더 / 푸터 처리
- Excel 텍스트 셀 처리

## 설치

```bash
pip install -r requirements.txt
```

## API 키 설정

`.env.example` 파일을 복사해서 `.env` 파일을 만들고 아래처럼 입력하세요.

```bash
OPENAI_API_KEY=본인_API_키
OPENAI_MODEL=gpt-4.1-mini
```

## 실행

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열립니다.

## 사용 방법

1. 파일 업로드
2. 번역 언어 선택: 중국어 또는 영어
3. 번역 스타일 선택
4. 번역 시작 클릭
5. 번역 파일 다운로드

## 용어집 형식

선택 사항입니다.

엑셀 또는 CSV의 첫 번째 컬럼을 원문, 두 번째 컬럼을 번역어로 인식합니다.

예시:

| source | target |
|---|---|
| 그놈은 드래곤 | 龙魂 |
| 지크프리트 | 齐格菲 |

## 한계

- 이미지로 들어간 글자는 번역하지 못합니다.
- 일부 SmartArt / WordArt는 누락될 수 있습니다.
- PPT는 번역 후 글자 넘침과 폰트를 최종 확인하는 것을 권장합니다.
- 암호화된 파일은 지원하지 않습니다.

## 추천 사용 방식

1. 이 앱으로 1차 번역 파일 생성
2. 번역 로그 엑셀로 누락/오역 확인
3. PPT는 글자 넘침과 폰트만 최종 검수
